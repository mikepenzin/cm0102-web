Privacy

Saved games

Your saves stay in this browser. Download one to keep a copy on your device or to play it on another one; upload a .sav file to play it here.

Tactics

The tactics you saved on the tactics screen (Tactics, Save As). Download one to keep it or to use it in the PC game; upload a .tct file, from the PC game or from a friend, then use Tactics, Load on the tactics screen. A preset's .pct file works too.

Data sets for new games

Your own databases: a copy of the game's data that you edited, or one you uploaded (an Update Team database, for example). Use one to start a new game with it. Upload a database as a .zip, or as its .dat files together; a .rar or .7z must be unpacked and zipped first.

Your saved games

Save in the game as usual. The saves stay in this browser. Saved games downloads them as files and uploads them again, also to and from the desktop game, and its Edit button changes the players of a save: ability, attributes, positions, age.

Editor

The Editor button changes the players of a saved game, or makes a data set for new games: your own copy of the database, where you change players and add new ones. Saved games lists the data sets: Use one for your next new game, download it as a zip, or upload one (an Update Team database, for example).

Cloud saves

With Cloud Saves, each save goes to the cloud, and the game started on another computer or iPad gets it. Sign in with Google (Sign in, in the bar) to get them. Pricing · Privacy

As an app

Add the page to the home screen (on an iPad: Share, then Add to Home Screen) or install it from the address bar. It then opens without the browser's bars, and it starts without a connection once it has run.
